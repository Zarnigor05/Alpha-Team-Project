1. Project Overview
- Selected Category: Option B: Data Analysis & Prediction (Multiple Linear Regression)
- Project Title: Meliorative Analysis and Prediction: Studying Irrigated Lands and Soil Salinity Levels in Uzbekistan Using Multiple Linear Regression
- Project Objective: To utilize official open data from the Ministry of Water Resources of the Republic of Uzbekistan to build a Multiple Linear Regression model that analyzes and predicts the relationships between total irrigated areas and various soil salinity categories (non-saline, slightly saline, moderately saline, and heavily saline soils) across different regions.

2. Verified Data Source
- Data Provider: Official Open Data Portal of the Republic of Uzbekistan (data.egov.uz).
- Dataset Name: Meliorative programs for land improvement and development of new lands, provided by the Ministry of Water Resources of the Republic of Uzbekistan.
- Parameters Used: Total irrigated land, non-saline areas, and different degrees of soil salinity categorized by regions (CSV/XLS format).
